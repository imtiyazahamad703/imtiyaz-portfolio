## 🌟 Overview

Welcome to my personal portfolio! This is a modern, highly interactive, and fully responsive 3D web application designed to showcase my journey as an **AI Full-Stack Engineer**. It features custom 3D character animations, dynamic timelines, and a sleek, immersive UI/UX powered by React and Three.js.

The platform is designed to highlight my expertise in building scalable microservices, AI-driven applications, and high-performance web platforms.

---

## 🚀 Key Features

*   🌍 **3D Interactive Character:** A custom, fully rigged 3D avatar built using Three.js and React Three Fiber that responds dynamically.
*   📜 **Immersive Timeline:** A modern, scroll-triggered experience detailing my professional journey and education.
*   🎨 **Dynamic UI/UX:** Glassmorphism styling, vibrant gradients, and smooth scroll animations via Tailwind CSS and GSAP.
*   💻 **Project Showcase:** A unique stacking-card layout on desktop and clean vertical scroll on mobile to beautifully display my top projects (like AI BidStream, ExerLytix, etc).
*   📱 **100% Responsive:** Carefully crafted breakpoints ensuring a flawless experience on everything from ultra-wide monitors to iPads and smartphones.

---

## 🛠️ Tech Stack

*   **Frontend Framework:** React.js, Vite
*   **Styling & Animations:** Tailwind CSS, GSAP
*   **3D Rendering:** Three.js, React Three Fiber, React Three Drei
*   **Form Handling:** EmailJS
*   **Deployment:** Vercel

## 🧑‍💻 How to Run Locally

### 1. Clone the Repository

```bash
git clone https://github.com/imtiyazahamad703/Imtiyaz-Portfolio.git
cd Imtiyaz-Portfolio
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Start the Development Server

```bash
npm run dev
```

### 4. Build for Production

```bash
npm run build
```
